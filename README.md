# Pregnancy Nutrition Tracker App 🤰

A personalized nutrition monitoring app for pregnancy, designed for vegetarian diet with egg consumption.

## 📦 What's Included

- `pregnancy-nutrition-tracker.html` - Main app file
- `manifest.json` - App configuration for mobile installation
- `sw.js` - Service worker for offline functionality
- `INSTALLATION_GUIDE.md` - Detailed installation instructions

## ⚡ Quick Start

### Easiest Way (Recommended):

1. **Upload all files to Netlify:**
   - Go to https://app.netlify.com/drop
   - Drag the entire folder
   - Get your app URL instantly!
   - Open URL on phone → Install app

### Or Use Locally:

1. Keep all 3 files in the same folder
2. Open `pregnancy-nutrition-tracker.html` in Safari (iPhone) or Chrome (Android)
3. Add to Home Screen

## 🎯 Features

✅ Daily meal logging (breakfast, lunch, dinner, snacks)
✅ Tracks 8 critical pregnancy nutrients
✅ Iron focus (helps with hemoglobin levels)
✅ Vegetarian + egg-friendly recommendations
✅ Trimester-specific advice (currently 21 weeks)
✅ Weekly nutrition analysis with personalized suggestions
✅ Identifies missing nutrients (e.g., "no fiber in 3 days")
✅ Works offline after installation
✅ All data saved locally and permanently
